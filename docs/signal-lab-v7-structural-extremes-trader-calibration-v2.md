## Зафиксированная иерархия уровней

Экстремум принадлежит таймфрейму, на котором он сформирован. При переходе на младший график его исходный таймфрейм не меняется.

Видимость контекста сверху вниз:

- 1m: 1m + 5m + 15m + 1h + 4h + 1d;
- 5m: 5m + 15m + 1h + 4h + 1d;
- 15m: 15m + 1h + 4h + 1d;
- 1h: 1h + 4h + 1d;
- 4h: 4h + 1d;
- 1d: 1d.

1m и 5m — локальные уровни. Они отображаются только за последние 24 часа. Старшие уровни живут как собственные уровни до пробоя и могут быть видны на младших графиках.

Близкие уровни одного направления разных ТФ объединяются в multi-TF cluster. Основным остаётся самый сильный старший ТФ, например `H 4h + 5m · ×2`. Количество атак не суммируется между ТФ, чтобы одно и то же взаимодействие цены не считалось дважды.

Структурная сила растёт по иерархии `1m < 5m < 15m < 1h < 4h < 1d`. Это означает приоритет уровня в контексте, а не доказанное количество стопов за ним. Потенциальную концентрацию ликвидности затем нужно подтверждать стаканом, сделками, OI и ликвидациями.

## Семантика атак

- само формирование HIGH/LOW = атака ×1;
- первый отдельный возврат к зоне = ×2;
- следующий отдельный возврат = ×3;
- точного совпадения цены не требуется: небольшой недоход в пределах адаптивной зоны считается атакой;
- непрерывная проторговка внутри зоны остаётся одной атакой;
- новая атака появляется только после полноценного отхода и повторного rearm.

Пользователь визуально подтвердил эту семантику на UBUSDT 15m.

- ATR переведён в робастный процентный расчёт с trimmed mean;
- ATR-компонент ограничен потолком для каждого ТФ;

- URL фиксирует symbol / tf / endAt;
- Binance Futures tickSize выбирается строго по запрошенному символу;
- пакетный replay не создаёт полный snapshot после каждой свечи;
- формирование уровня включено в ordinal атак как ×1.

## V3.3 — multi-timeframe level map

Добавлен отдельный слой multi-TF контекста:

- `signal-lab-v7-multi-timeframe-levels.js` — правила видимости, сила, 24h horizon для 1m/5m, clustering и native labels;
- `signal-lab-v7-multi-timeframe-review-runtime.js` — подгружает старшие ТФ и накладывает их на младший график;

- совпавшие уровни отображаются через самый старший источник, например `H 4h + 5m`.
