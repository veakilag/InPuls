# Security policy

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion, pull request, or social channel.

Use GitHub's private vulnerability reporting for this repository. Include:

- the affected URL, file, and version;
- reproducible steps or a minimal proof of concept;
- the expected and actual behavior;
- the likely impact;
- any suggested mitigation.

Do not access other users' data, disrupt availability, run destructive tests, or retain data obtained during testing.

The project owner will acknowledge a complete report, validate the issue, and coordinate a fix before any public disclosure.
